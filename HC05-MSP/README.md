# LFish · 青鳍 0.3.0

## 本次更新

- 固定横屏、全屏显示；控制页一屏容纳双摇杆和按钮。
- 真实连接后点“开始无电机通道测试”，确认拆桨、电机未连接后才发送横滚、俯仰、偏航，范围 1400–1600，松手回 1500。
- 油门与 AUX1–4 固定 1000；需沿用 AUX 高值解锁的配置。左杆上下不发送升降，解锁与定高未开放。本版仅用于无电机台架测试。
- 电脑 Betaflight 退出 CLI，打开“接收机”页面观察通道变化。
- 切后台/锁屏停止测试，但不主动断开现有蓝牙。返回后需手动重新开始测试，切换状态页也会停止测试。系统清理进程仍可能断连，本版没有后台保活服务。
- 飞控超过 1.5 秒无应答则停止测试，界面输入心跳超过 350ms 则方向回中。

安装 LFish-0.3.0.apk 覆盖升级。包名与签名保持一致。源码在 source/，图标在 assets/，电脑预览在 preview/。

已通过编译、协议测试、通道映射/偏航限幅/油门与 AUX 最低值测试、APK 签名验证，以及 900×390 横屏页面无滚动检查。尚未验证新版真机后台与 RC 发送行为。

定高逻辑与实际飞行尚未实现；本版不是飞行遥控器。
